Tui Dui Man The Arena

แนวเกม: Top-Down Action RPG / Arena Survival

เอาชีวิตรอดในลานประลอง กำจัดศัตรูเพื่อเก็บ EXP อัปเลเวลเพิ่มค่าพลัง และใช้สกิล Ultimate เอาชีวิตรอดให้ได้นาน ที่สุด

ฟังก์ชันหลักในเกม
1. ระบบตัวละคร และ การต่อสู้:

-เคลื่อนที่มุมมองด้านบน โดยกดคลิกเลือก ตำแหน่งบนพื้นประลอง ตัวละครจะเดินไปตาม พื้นที่เป้าหมาย
-กด Spacebar เพื่อโจมตีสร้างความเสียหาย ใส่เป้าหมาย
-สกิล Ultimate (กด R) ทำดาเมจวงกว้าง รอบ ตัว พร้อมแสดงหลอด Cooldown บน UI
-ระบบอัปเลเวล ขยายขีดจำกัด Max HP และ Max EXP ทุกครั้งที่เลเวลเพิ่มขึ้น

2.ระบบศัตรู และ Al:

-ศัตรูใช้ NavMesh เดินไล่ตามผู้เล่นอัตโนมัติ พร้อมทำการโจมตี
-เมื่อศัตรูถูกกำจัดแล้วดรอปไอเทม ExpOrb

3. ระบบ UI และการเปลี่ยนฉาก :

-HUD หน้าเกม: แสดงหลอด HP, EXP, Ulti Cooldown
-Main Menu: มีปุ่ม PLAY สำหรับเข้าเกม / EXIT สำหรับปิดเกม
-Game Over Menu: มีปุ่ม TRY AGAIN สำหรับเริ่มใหม่ / MAIN MENU สำหรับกลับ หน้าหลัก
